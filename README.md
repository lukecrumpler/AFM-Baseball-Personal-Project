# ⚾ MLB Player Stats Comparison App

This Streamlit app lets users compare career stats of select MLB players from 2019–2024. Visualize key offensive metrics like batting average, OPS, WAR, and more.

## 🔧 How to Run the Code

```bash
# Install required packages
pip install -r requirements.txt

# Or manually install
pip install streamlit pandas matplotlib pybaseball

# Launch the Streamlit app
streamlit run Baseballpersonalproject.py
